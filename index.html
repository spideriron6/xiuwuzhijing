生活篇

人生在世, 不能像宠物一样只为吃饭, 须思考进取, 以明事理. 大作家狄更斯说过：...这是最伟大的时代, 这是最黑暗的时代...我非常认可他的观点. 林肯总统说过：...绝不可能在所有的时间内欺骗所有的人... 可是如果在一片愚昧了数千年之久的土地上呢. 因为希腊的文化从未侵染过这片土地. 我们这个星球的寻常人的生活基石是由人权和普选构筑而成, 没有人权和普选的生活便成了水中浮萍, 多少人祸多少泪. 那么, 生活的目标何在? 或者说人生的意义何在? 我认为人生的意义有二: 第一是过自己想要的生活. 第二是传承. 传承美, 传承须历经磨砾方可成就的有价值的事物. 1. 什么是人权? 2. 什么是普选? 3. 为什么要有人权? 4. 为什么要有普选?

1. 儿童教育App

gcompris是教育软件, 适合从幼儿园到小学低年级的孩子们. gcompris含有上百个寓教于乐的游戏, 涵盖了逻辑, 数学, 画画, 音乐, 计算机, 棋类, 物理, 环境, 历史, 地理, 词汇等许多类别, 呈现的内容相当广泛. gcompris的网址: https://gcompris.net 测试平台: 不同平台的安装方法是不一样的, 当前所使用的测试平台为: Ubuntu 22.04.5;Kernel 6.8.0;Arch x86_64 gcompris的安装方法: 先连接互联网, 然后打开Terminal App, 执行更新命令: sudo apt update 然后执行安装命令: sudo apt --force-yes -y install gcompris-qt 下面是gcompris的部分界面, 请点击图片查看大图:

2. 计算机科学启蒙App

TurboWarp和Scratux是计算机科学启蒙软件, 适合小学阶段的孩子们. TurboWarp和Scratux有丰富的图片和声音素材, 通过简化的计算机语言的控制, 就能制作出很棒的视觉特效, 可以用于制作视频,动画,游戏等, 并且还能生成可以独立运行的App. TurboWarp的功能较多, 比如字体可以放大. 不过Scratux有Tutorials, 特别适合初学者, 但是第一个Tutorial存在顺序错误, 正确示例请看下图. TurboWarp的网址: https://desktop.turbowarp.org 测试平台: 不同平台的安装方法是不一样的, 当前所使用的测试平台为: Ubuntu 22.04.5;Kernel 6.8.0;Arch x86_64 TurboWarp和Scratux的安装方法: 先连接互联网, 然后打开Ubuntu Software App, 搜索TurboWarp, 点击搜索项进入详细介绍页面, 再点击右上方的Install. 再次搜索Scratux, 安装方法同前. 下面是TurboWarp的部分界面和Scratux第一个Tutorial的第一步, 请点击图片查看大图:

3. 计算机科学启蒙硬件

microbit是计算机科学启蒙硬件, 适合小学阶段的孩子们. microbit的网址: https://microbit.org microbit可以看作是一台超小的计算机, 有cpu, storage, 还配备了sensor, led light, button, speaker, microphone等基本的输入输出. 使用简化的计算机语言编写程序, microbit就变成了一个充满乐趣的玩具, 更是一个有用的工具. 如何让microbit运行所编写的程序呢？不同平台的方法不一样. 当前所使用的测试平台为: Ubuntu 22.04.5;Kernel 6.8.0;Arch x86_64;Firefox 152.0.3 第一步: 连接互联网, 用usb线连接microbit和电脑, 使用firefox打开microbit网址. 第二步: 点击顶部的菜单项“Projects", 勾选左边的“MakeCode". 详细请参考下图的蓝色方框. 第三步: 右边任选一个project, 点击进入详细介绍页面. 点击左边的“Step 2: Code it", 再点击“Open in MakeCode". 详细请参考下图的蓝色方框. 第四步: 点击左下方的“Download", 再点击工具栏上的"downloads", 点击"Show in folder"以打开Files App, 复制hex文件. 详细请参考下图的蓝色方框. 第五步: 在打开的Files App中点击"MICROBIT", 粘贴hex文件. 等待microbit完成文件的写入. 完成后microbit会自动重启. 详细请参考下图的蓝色方框. 下面是microbit的部分界面, 请点击图片查看大图:

音乐篇

古典音乐可为精神的依托, 能使心灵得以慰藉. 以小提琴演奏家Andre Rieu为代表的乐团, 成功的在音乐会中引入多种元素, 让古典音乐的雅俗共赏成为了可能. S.E.N.S.音乐组合所创作的电子音乐的特点是大气磅礴. 触及心灵的歌词, 天籁般的声音, 流连忘返的旋律, 近乎完美的演绎, 在流行音乐中同时具备这四点的便是经典之作了. 杰出代表作有: Sarah Brightman的"Winter In July" Rod Stewart的"Hold On" Roberta Flack的"Tonight I Celebrate My Love" 最后, 谨以这些美妙的音乐, 向文中所提到的App的设计者, 开发者, 贡献者送上美好的祝福, 并致敬以诚挚的谢意.
